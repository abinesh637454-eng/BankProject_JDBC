# 🏦 Bank Project - REST API

A simple **Bank Account Management REST API** built using **Java and Spring Boot**.  
This project demonstrates the basic **CRUD operations** using HTTP methods such as **GET, POST, PUT, and DELETE**.

The project is designed as a beginner-friendly backend application to understand how REST APIs work with Spring Boot.

---

## 🚀 Features

- ✅ Create a new bank account
- ✅ Get all bank accounts
- ✅ Get a bank account by ID
- ✅ Update an existing bank account
- ✅ Delete a bank account
- ✅ RESTful API architecture
- ✅ JSON request and response handling
- ✅ Tested using Postman

---

## 🛠️ Technologies Used

- **Java**
- **Spring Boot**
- **Spring Web**
- **Maven**
- **REST API**
- **JSON**
- **Postman**
